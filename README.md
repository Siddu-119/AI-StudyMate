# 📚 AI StudyMate — AI-Powered Learning Companion

> Learn smarter. Understand better. Achieve more.

AI StudyMate is an AI-powered study assistant designed to help students learn concepts, ask academic questions, and make studying easier through an interactive web application.

## ✨ Features

- 🤖 AI-powered study assistance
- 💬 Interactive question-and-answer experience
- 📖 Student-friendly learning support
- ⚡ Responsive and user-friendly interface
- 🧪 Demo mode for exploring supported features

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- CSS

**Backend**
- Node.js
- Express.js

**AI Integration**
- Google Gemini API

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd AI-StudyMate
```

### 2. Install Dependencies

```bash
cd server
npm install
```

Open another terminal:

```bash
cd client
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in the server directory and configure your Gemini API key and other required environment variables.

Never commit API keys or secrets to GitHub.

### 4. Run the Application

Start the backend using the script configured in `server/package.json`.

Start the frontend:

```bash
cd client
npm run dev
```

Open the local URL provided by Vite.
